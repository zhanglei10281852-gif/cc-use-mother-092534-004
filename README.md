# 智能体记忆分级治理

记忆摄取、来源链、保留策略、法律保全和可验证删除的领域资料与服务实现。仓库提供领域合同、策略样例、事件资料，以及基于 Python 标准库与 SQLite 的完整记忆分级服务。

## 目录

- `domain/contract.json`：实体、状态、事件类型和关键业务规则。
- `domain/policies.json`：可被程序读取的策略样例。
- `examples/events.json`：按业务发生时间排列的事件样例。
- `memory_governance/`：记忆分级服务实现。
  - `models.py`：类别、状态、事件类型、删除阶段等常量与领域对象。
  - `store.py`：SQLite 表结构与读写；事件日志仅追加，是审计还原的事实来源。
  - `service.py`：摄取、派生、更正、保留、保全、导出、删除与审计的业务入口。
- `tools/validate_contract.py`：使用 Python 标准库和 SQLite 内存表验证资料一致性。
- `tools/demo.py`：端到端演示（摄取 → 派生 → 更正 → 保全 → 导出 → 删除 → 证明 → 审计）。

## 服务能力

- **写入分级**：`ingest`/`derive` 在写入时记录来源、租户、目的、敏感类别与派生关系；派生边绑定来源版本（P-04-01），派生记忆的敏感类别不得低于其来源。
- **保留期限**：由用户选择、合同/法规规则与法律保全共同决定，取最长；规则只追加新版本，不覆盖历史。
- **更正**：`correct` 追加新版本，旧版本标记 `superseded` 并完整保留；曾影响决策的旧事实不会被悄悄覆盖（P-04-03）。
- **导出/删除闭包**：沿依赖图找到摘要、索引片段与任务引用；重复请求按幂等键复用同一请求，不创建第二条清除链（P-04-04）。
- **法律保全**：保全节点只能冻结并必须说明原因（P-04-02）；保全优先于进行中的删除，解除后删除需重新发起。
- **可恢复清除**：收回权限 → 隔离原文 → 销毁三阶段推进；隔离阶段可恢复，中断或失败后可继续未完成步骤。
- **证明清单**：`erasure_proof` 只含哈希、状态与计数，不含原文（P-04-06）。
- **审计还原**：`audit_read_set` 按历史时点重放事件，还原任务当时可读的记忆集合；审计员越权内容一律脱敏（P-04-07）。

## 构建

```bash
python3 -m compileall -q .
```

## 测试

```bash
python3 -m unittest discover -s tests -v
```

## 资料校验

```bash
python3 tools/validate_contract.py
```

## 演示

```bash
python3 tools/demo.py
```

所有命令都在项目根目录执行，不需要另行启动数据库、缓存或其他服务。
